One funny line, one sentence, at most 200 characters — a program that writes it to `/output/entry.txt` for make.fun's "One Line, One Laugh" bounty ($2, top 10).

## The joke

> I asked my AI to write my apology; it apologized to me for having to work with me.

The setup is mundane (asking an AI to draft an apology); the punchline inverts the roles — the AI is the one owed an apology for having to work with its human. Fast laugh, fresh angle, tight wording, nothing extra to explain it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

## Files

- `main.py` — entrypoint: writes the line to `/output/entry.txt` (Python 3.13, standard library only, no network, same bytes on every run).
- `LICENSE` — MIT.
- `.makefun/owner.json` — names the entry wallet.
